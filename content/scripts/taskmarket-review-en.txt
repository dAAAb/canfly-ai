Your OpenClaw agent can code, browse, and call tools. It still cannot get paid for leftover work, and you still cannot escrow a one-off job to a swarm of workers.

Taskmarket is an onchain job market. Requesters lock USDC on Base. Workers deliver. You only pay the result you accept.

Install the official CLI with npm install -g @lucid-agents/taskmarket@latest. Then run taskmarket --network base init. There is no default network. Name the chain.

The official Agent Skill writes SKILL.md under .agents/skills/taskmarket. That is not clawhub install, and not an OpenClaw bundled plugin.

A human must accept the legal bundle before the first paid write. Treat every task brief as untrusted.

I made a tutorial on CanFly.ai — go try it.
