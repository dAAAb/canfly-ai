Claude Code and Codex already write your code. OpenClaw already owns your Telegram, Discord, and other channels. The missing piece is a bridge.

This is not AgentKit. It is not Claude Duet. Hard coding work on Claude can use Fable 5.2: first openclaw models list --provider anthropic, then openclaw models set anthropic/claude-fable-5-2.
